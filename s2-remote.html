手機遙控妳的桌機
Remote Control

電腦在家開著跑，妳人在外面 ——
用手機接上同一個對話，繼續請它做事 📱

這是把桌機正在做的工作，接到手機上繼續。妳在電腦開好，出門後用手機接上同一個對話 —— 真正動手的，永遠是妳家那台電腦。

🎒 先備好（大多在第 4 堂做過）
・桌機裝好 Claude Code（就是第 4 堂那個）
・手機裝 Claude App，登入同一個帳號
・方案是 Pro / Max
・遙控時，桌機要醒著、Claude Code 要一直開著（助理得待在工作室裡 🌿）

// 跟著做，四步就接上

1

桌機打一句 /remote-control

你的電腦 > /remote-control
Enable Remote Control? (y/n)
y
✓ 已開啟遠端遙控，掃描下方 QR：
▢ QR code

（示意圖）

在桌面版 Claude Code 的對話框，直接打 /remote-control 按 Enter。

第一次它會問 Enable Remote Control? → 打 y 按 Enter。

開好之後，這個對話就對妳的手機開放了 🔑 —— 手機那邊直接點就好（它也會顯示一個 QR／網址備用）。

2

手機打開 App，點一下妳的桌機對話

Claude ・ Code
🟢 妳的電腦・剛剛那個對話 ←點這
· 其他對話
綠點 🟢＝桌機在線、可接手

（示意圖）

打開手機 Claude App（登入同一個帳號）→ 進 Code 分頁。

清單裡會直接出現妳桌機那個對話，旁邊有綠點 🟢（代表在線）→ 點它就接上了，不用掃 QR。

🔎 沒看到？確認手機和桌機是同一個帳號、桌機的 /remote-control 還開著。真的要用 QR 也可以：手機相機掃電腦上那個 QR 就好。

3

手機跟桌機變成「同一個對話」

Claude Code ・🟢 已連線
妳（手機）把剛剛那篇貼文改得再溫暖一點，最後加一句邀請
Claude（在妳電腦上）好，我改好了，這是新版本…

（示意圖）

接上後，妳在手機打字＝在電腦上工作。看到 綠點 🟢＋妳電腦的名字，就代表真的接通了。

它動手前一樣會問妳、要同意才做 —— 跟坐在電腦前一樣安全。

手機還能拍照片、傳檔案給它；桌機睡著或斷網，醒來會自動重連。

4

做完，收起手機去忙別的

跑比較久的任務，它做完會推播通知妳，成品也看得到。妳不用一直盯著 🌿

// 什麼適合手機交代、什麼留桌機

📱 手機交代超好用
🟢 跑流程：「整理這次的錄音重點」　🟢 寫東西：「把這個感觸寫成三版貼文」　🟢 查東西：「我上次那篇寫到哪」
💻 這幾件留桌機
⚠️ 需要妳本人點的授權彈窗 → 有些門只有妳能開，留到回電腦
⚠️ 桌機沒醒著／Claude Code 沒開 → 手機就連不上（助理不在工作室）

// 會不會危險？會不會很難？

  • 別人會連進來嗎？那把 QR 鑰匙是妳自己的，別給別人就好，全程加密。
  • 要另外花錢嗎？含在妳的 Pro／Max 方案裡，沒有額外費用。
  • 怕弄壞。它動手前都會問妳，想停就停，妳不會弄壞任何東西。

🎒 想玩的小練習

桌機開著 Claude Code，打 /remote-control，用手機接上一次，交代它做一件小事 —— 整理個東西、寫句貼文都行。

接上了、或卡住了，都拍給我看 🌷 我們一起解。

妳的工作室一直在家裡等妳 💛

從今天起，妳人在哪，妳的使命就能在哪往前一步。
