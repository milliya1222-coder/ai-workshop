BEFORE WE START

上課前，把它準備好

三件事，大概 15 分鐘。
裝不起來完全沒關係 —— 第一堂我們一起弄 🌿

這一頁是給 9/9（三）第一堂 的課前準備。

如果妳現在時間很滿，只要做到 第 ① 步跟第 ② 步 就好，第 ③ 步當晚一起裝。真的不用有壓力 —— 第一堂本來就有留裝機的時間。

// 妳會裝到什麼

  • 一個 Claude 帳號 —— 妳跟它說話的地方
  • 一個付費方案 —— 免費版做不了我們要做的事，這個要先備好
  • 一個桌面 App —— 放在妳電腦上，開起來就能用

準備好這三個，明晚一開場就能直接動手 ✨

// 一步一步來

1

註冊一個 Claude 帳號

  1. 用手機或電腦打開 claude.ai
  2. 選「Continue with Google」，用妳平常的 Google 帳號登入最快
  3. 看到對話框跳出來，就成功了 —— 先隨便跟它說一句話試試
💡 建議用妳工作在用的那個 Google 帳號。第二堂我們要把 Google 雲端串上去，同一個帳號會省很多事。
2

訂一個付費方案（這一步最重要）

免費版有很緊的用量限制，一堂課做不完一件事就會被停住 —— 那個挫折感，我不想讓妳在第一晚遇到。

  1. 在 claude.ai 左下角點自己的名字 → Upgrade plan（升級方案）
  2. 選 Pro —— 這是我們這四堂夠用的方案
  3. 價格約 US$20／月（台幣大約六百多，依匯率浮動；也有年繳較便宜的選項）
  4. 刷卡完成，左下角會出現 Pro 的標記
⚠️ 先訂月繳就好，不要年繳。
先跟它相處一個月，確定它真的幫得上妳的工作，再決定要不要長期留著。這是我自己的原則，也想給妳同一個 🌿
💛 我知道這是一筆錢。但這四堂是「做中學」—— 妳要真的做出東西，工具就得跟得上妳。這是整堂課唯一需要另外花的費用。
3

下載桌面 App

網頁版也能用，但桌面 App 開起來更快、也比較不會跟一堆分頁擠在一起。

🍎 Mac

  1. 打開 claude.ai/download
  2. 點 Download for Mac
  3. 下載完打開那個檔，把 Claude 的圖示拖進 Applications
  4. 從「應用程式」打開它，用第 ① 步的帳號登入
  5. 如果跳出「無法打開，因為來自身分不明的開發者」→ 到「系統設定 → 隱私權與安全性」，往下找到 Claude，按「仍要打開」

🪟 Windows

  1. 打開 claude.ai/download
  2. 點 Download for Windows
  3. 下載完點兩下那個檔，一路按下一步
  4. 從開始功能表打開 Claude，用第 ① 步的帳號登入
  5. 如果 Windows 跳出藍色的「已保護您的電腦」→ 點「其他資訊」→「仍要執行」
裝好怎麼確認？ 打開 App，跟它說「哈囉」，它有回妳，就成功了 ✅ 截圖丟到群組讓我知道，我會幫妳確認。

// 上課那晚，我還會需要什麼

  • 一份妳工作上真的要用的文字 —— 課程介紹、服務說明、商品文案、一段語音逐字稿都可以。
    不用整理過，越原始越好。我們就是要拿它來練。
  • 電腦（不是手機 —— 手機看回放可以，但動手要用電腦）
  • 耳機，如果方便的話

沒帶也沒關係，當天我這邊有備用的範例可以借妳練 🌷

🆘 卡住了？這樣做

  • 找不到下載按鈕 → 網站是英文的，別怕，看到 Download 就對了
  • 刷卡失敗 → 換一張卡試試；有些銀行對海外訂閱會擋，打去開通就好
  • 登入一直轉圈 → 關掉重開，或換一個瀏覽器
  • 完全不知道自己在哪一步 → 截圖丟群組，這是最快的方式

真的，卡住非常正常，不是妳的問題。第一堂本來就留了時間一起解 💛
