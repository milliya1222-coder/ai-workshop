AI Agent 是什麼？
還有這個月，三家在拚什麼

一頁看懂「會自己動手的 AI」——
還有 Anthropic／OpenAI／Google 現在各自強在哪 🤖

最近一定常聽到「AI Agent（AI 代理人／智能體）」。它跟我們平常聊天的 AI 差在哪？
這頁用最白話講清楚，順便告訴妳三家系統這個月的差別 —— 不用記型號，記重點就好 🌿

// 一、AI Agent 到底是什麼

用一個比喻最快懂：

💬 聊天機器人

妳問一句、它答一句。像跟人問路 —— 它告訴妳怎麼走，但腳還是妳自己在走。

🤖 AI Agent

妳給它一個目標，它自己動手去完成。像請一位助理：「幫我把這件事辦好」，它就去辦。

差別在 Agent 會自己跑一個循環：

① 規劃（拆成小步）→ ② 動手（會用工具）→ ③ 檢查、修正↻ 直到完成

它還會記得前面做過什麼，不用妳每一步都盯著下指令。

💡 其實妳已經用過了 ✨妳在 Claude 裡說「幫我建一個資料夾、把這份文件改好、做成一頁網頁放上線」—— 它自己一步步完成，那就是 AI Agent 的雛形。妳這四堂課，一直在跟一個 agent 工作。

為什麼今年特別紅：2026 是 AI Agent 從「實驗」變成「真的能用」的一年。研究機構 Gartner 估計，到今年底約 40% 的企業軟體會內建 AI Agent（去年還不到 5%）。

// 二、這個月，三家在拚什麼

先講一句最重要的：現在最頂尖的幾個模型，聰明程度的差距是史上最小的。所以選哪一家，重點不是「誰最聰明」，而是 —— 妳要做什麼、習慣哪個生態。

Claude
ANTHROPIC
最新：Fable 5.1（9/1）、Opus 4.8。
（就是我們這堂課用的這家）
最擅長

寫作與內容、策略思考、寫程式、誠實不亂編、動手做事（agent）很穩。

ChatGPT
OPENAI
最新：GPT-5.5、GPT-5.6（Sol／Terra／Luna 系列）。
最擅長

生態最廣、多媒體（圖片／語音／影片）、把很多工具串起來自動化。

Gemini
GOOGLE
最新：Gemini 3.6 Flash、3.1 Pro。
最擅長

研究、一次讀超長資料、事實查證、跟 Google（Gmail／Docs／Drive）整合最順。

// 三、那我該用哪一個？

用「妳想做什麼」來選，比較實際：

寫貼文、文案、有溫度的深度內容Claude
要生圖／語音／影片、把一堆工具串成自動化ChatGPT
讀超長文件、做研究、跟 Google 服務整合Gemini
學「叫 AI 動手做事」（像我們課這樣）Claude
🌷 最誠實的一句：三家都很強，也都在互相追、每個月都在變。與其一直找「最好的那個」，不如選一個「妳用得順、願意天天打開」的—— 熟悉一個、把它用深，比每個都淺淺碰過有用太多。
⏳ 這頁是「2026 年 9 月」的快照。模型型號每個月都在變、名字會越換越多 —— 型號忘了沒關係，記住觀念就好：AI Agent ＝ 妳給它一個目標，它自己規劃、動手、修正，一路做到完成。
