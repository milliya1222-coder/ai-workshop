// 先懂一個比喻（最重要）

🏡

桌機是妳的工作室，Claude 是裡面的助理

  • 平常妳在工作室裡跟助理面對面交代事情
  • 手機遙控 = 妳出門了，還能打電話回工作室，請助理繼續幫妳做
  • 妳不用在場，事情照樣在工作室裡完成 ✅
  • 助理能把做好的成品「拍給妳看」，傳到妳手機 ✅

記住這個畫面，等一下所有「能做／不能做」妳都會秒懂。

// 三步驟：手機接上桌機

1

在電腦打一句指令

電腦打這個/remote-control

會跑出一串網址 —— 這串就是「工作室的鑰匙」🔑

2

叫它把網址變成 QR code

貼這句把這個網址做成一個 QR code，方便我用手機掃

不用自己找網站做 —— 它會在妳自己的電腦上做好，不外流。

3

手機掃 QR，就接上了

  • 用手機相機掃那個 QR code
  • 點開連結 → 妳的手機就跟電腦是同一個對話了 🎉
想確認有沒有接上？手機打跑一個指令，顯示電腦名稱

如果出現的是妳家電腦的名字，就代表真的接通了 —— 它做事的地方是妳的電腦，不是手機。

// 手機、iPad、平板都行

📱💻 不是只有手機 —— 任何裝置都能當「遙控器」
只要那個裝置有瀏覽器、登入妳同一個帳號，就能連進電腦。手機、iPad、另一台電腦都可以。
做事的永遠是妳家那台桌機，遙控器是誰不影響。
✨

iPad 其實更好用

  • 螢幕大：成品傳回來看得清楚、改起來不費眼
  • 打字舒服：交代複雜的事、貼長段落都比手機順
  • 能分割畫面 + 配鍵盤：接上鍵盤就像半台筆電

連法一樣：掃同一個 QR、或把那串網址傳到 iPad 點開，就進同一個對話了。甚至手機和 iPad 可以同時連同一個工作室 🌙

// 什麼能丟手機、什麼留電腦

📱 手機丟給它超好用（助理在工作室能做的）
🟢 跑流程：「整理這次陪伴的錄音」「把這個媽媽加進名單」
🟢 查東西：「我上次那篇貼文寫到哪了」
🟢 寫東西：「幫我把這個感觸寫成 3 版貼文」
💻 這幾件要留電腦 / 要繞一下路
⚠️ 手機的照片要給它 → 先放進「你們共用的櫃子」（Google 雲端硬碟），它才拿得到。直接傳進對話，它看得到、但存不進電腦。
⚠️ 要它幫妳點網頁按鈕 → 助理只在工作室裡動手，不會幫妳操作瀏覽器。
⚠️ 要妳本人點的授權彈窗 → 有些門只有妳能開，這種留到回電腦前做。

一句話記住邊界 👉 想著那個比喻就好：助理能在工作室做的，手機都能交代；需要「看畫面、開妳專屬的門」的，留給電腦。

// 會不會危險？會不會很難？

  • 會被別人看到嗎？　那串鑰匙是妳自己的，別給別人就好 —— 就像家裡鑰匙不會隨便給人。
  • 要另外花錢嗎？　不用，這是妳已經有的能力，今天只是把它打開。
  • 我怕用手機把它弄壞。　它動手前都會問妳，跟在電腦上一樣安全。一開始一直按同意就好，想停就關掉。妳不會弄壞任何東西。
