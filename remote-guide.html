// 方式 ①：Cowork —— 像傳訊息一樣派任務

✨ 最快的設定法：一句 /setup-cowork
懶得記下面的設定步驟？開一個新的 Cowork 對話，打 /setup-cowork 再按 Enter——Claude 會一步一步帶妳把 Cowork 設好，最後還給妳幾句「馬上能用的起手 prompt」，不是丟妳一個空白畫面。
🎁 現在到 8/5，Cowork 用量加倍——正好趁這波多接幾次任務。

// 方式 ②：Remote Control —— 掃 QR，手機接手操控

這個是「接手正在跑的工作」：妳在電腦開好，出門後用手機繼續同一個對話。妳課堂上裝的 Claude Code（終端機）就能用，不用另外裝 App。

你＄ claude remote-control
✓ 已開啟遠端遙控
掃描 QR 或用手機開啟連結：
▢ 按空白鍵顯示 QR

3手機跟電腦變成「同一個對話」

接上後，妳在手機打字＝在電腦上工作。看到綠點🟢＋妳電腦的名字，就代表真的接通了。
它動手前一樣會問妳、要同意才做——跟在電腦上一樣安全。

🌟 Remote Control 一句話
電腦打 claude remote-control → 手機掃 QR → 同一個對話接著聊。跑久了它會推播通知妳。

// 什麼手機丟給它好用、什麼留電腦

📱 手機交代超好用
🟢 跑流程：「整理這次陪伴的錄音」🟢 寫東西：「把這個感觸寫成 3 版貼文」🟢 查東西：「我上次那篇寫到哪」
💻 這幾件留電腦 / 要繞路
⚠️ 手機的照片要給它 → 先放進 Google 雲端硬碟，它才拿得到
⚠️ 要它幫妳點網頁按鈕 → 助理只在工作室動手，不幫妳操作瀏覽器
⚠️ 要妳本人點的授權彈窗 → 有些門只有妳能開，留到回電腦

// 會不會危險？會不會很難？

  • 別人會連進來嗎？　那把鑰匙（QR／配對）是妳自己的，別給別人就好。全程加密。
  • 要另外花錢嗎？　兩個都含在妳的 Pro／Max 方案裡，沒有額外費用。
  • 怕用手機弄壞。　它動手前都會問妳，跟在電腦上一樣安全。想停，一樣可以停。妳不會弄壞任何東西。
