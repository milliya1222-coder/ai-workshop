// 上半場：把重複的事，變一句話

1

找出妳每個月都在重做的那件事

有沒有一件事，妳每個月做超過兩次，而且每次步驟都差不多？

  • 客戶故事 → 整理成貼文
  • 語音心得 → 逐字稿 → 文章
  • 活動結束 → 感謝信 → 名單整理
  • 上週的回饋表單 → 整理成見證
  • 個案紀錄 → 整理成下次要注意的重點

挑一個，然後：

複製貼進 Claude我每個月都要做一件事，我想把它變成一個固定流程， 以後我只要說一句話，你就照著跑完。 這件事是：【描述它，越囉唆越好】 我現在的做法是：【一步一步講，包含妳的判斷跟眉角】 我不滿意的地方是：【哪裡很煩、哪裡常出錯】 請你： 1. 先把流程整理成清楚的步驟，跟我確認有沒有漏掉 2. 確認後，寫成一份「配方」，讓我以後貼給你就能直接跑 3. 告訴我，這流程裡哪些是你能做的、哪些一定要我自己判斷
💡 第 3 點才是重點。需要妳的判斷、妳的溫度、妳的責任的那一段，要留給自己 —— 這也是「真愛 AI」的意思。
2

把配方存起來、下次直接用

它給的那份配方，存成一個檔案（放進作業資料夾）。以後要用時：

下次要用時照這份配方幫我跑一次，這次的材料是：【貼上新內容】 【貼上妳的配方】
桌面 App 更省事：左邊建一個「專案 / Project」，把配方貼進專案說明欄。以後在那個專案裡對話，它就一直記得 —— 不用每次重貼 🌿

// 下半場：讓它動妳的電腦・還能手機遙控

3

先裝 Claude Code —— 讓它直接在妳的資料夾工作

到現在為止，妳都是把東西貼給它。要它自己動檔案、還要能手機遙控，需要先在桌機裝 Claude Code（終端機版）。

什麼是「終端機」？電腦裡有一個黑黑的視窗，可以直接打字叫電腦做事。大概長這樣：

你的電腦 > claude
Welcome to Claude Code 🎉
你的電腦 > 請幫我把這個月的回饋整理成三則見證…

別緊張 —— 它只是「另一種跟電腦說話的方式」：不用滑鼠，用打字。妳只要會複製、貼上、按 Enter 就夠了。

🍎 Mac

  1. Spotlight（⌘ + 空白鍵）搜「終端機」打開
  2. 貼這行按 Enter：
    curl -fsSL https://claude.ai/install.sh | bash
  3. 跑完關掉終端機再重開
  4. 打 claude 按 Enter，照指示登入

🪟 Windows

  1. 開始功能表搜「PowerShell」打開
  2. 貼這行按 Enter：
    irm https://claude.ai/install.ps1 | iex
  3. 跑完關掉 PowerShell 再重開
  4. 打 claude 按 Enter，照指示登入
⚠️ 那個黑黑的畫面不可怕。跑出一堆英文是正常的，讓它跑完就好。裝一半卡住也沒關係，今晚不用一次到位。

裝好之後第一句話：

貼進終端機請在我的桌面建一個叫「我的工作區」的資料夾， 裡面放一個 hello.txt，寫上今天的日期， 還有一段你作為我的工作夥伴想對我說的話。

它動手前會問可不可以 → 選 Yes。想停下來按 Esc 🌿

4

手機遙控 —— 出門也能交代它做事

桌機 = 妳的工作室，裡面有一位很能幹的助理。
手機遙控 = 妳出門了，還能「打電話回工作室」，請它繼續幫妳做事。

排隊接小孩、等咖啡的三分鐘，也能用手機交代它一件事 ✨　今晚我們一起接一次。

// 結業展示

🌷

拿出妳最想被看見的那一個

不用是最完美的，是妳自己最有感覺的那一個。每個人分享三件事就好：

  • 這是什麼、給誰的
  • 做的過程中，妳卡在哪
  • 妳怎麼過關的
💛 第二點最重要。妳卡住的地方，常常就是別人也卡住、但還沒說出口的地方。說出來，就是給彼此的禮物。

先幫自己整理一下：

複製貼進 Claude這四週我做了這些東西：【列一列】 過程中我最卡的是【⋯⋯】，後來我是這樣過關的【⋯⋯】 幫我整理成一段兩三分鐘可以講完的分享， 用我自己的語氣，不要客套話。 最後幫我寫一句：「這四週，我最想留給自己的一句話是⋯⋯」

📝 課後

  • 把最得意的作品貼到作業區的「⭐ 最得意的作品」欄，加一句話介紹
  • 留一段真實的見證 —— 我會另外把表單傳給妳 💛
  • 然後 —— 去用它。這四堂真正的成果，不在今晚，在接下來的每一週。

回放跟這四頁教材會一直留著。什麼時候想回來翻，它都在 🌿
