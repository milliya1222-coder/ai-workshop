進階上線 ・ GitHub Pages

把網頁放上 GitHub，
讓它永久在線上

拖 Netlify 是「快速給人看一次」；
GitHub Pages 是妳自己的一塊地 —— 免費、永久、有正式網址 🏠

我們的課程網站，就是這樣放上 GitHub 上線的。
它比拖檔案多幾個步驟，但一次設好之後：網址永遠有效、看起來更正式、之後改內容再上傳一次就更新。適合妳「真的要長期用」的那一頁。

// 兩條路，選妳順的

  • 🌿 最省事：叫 Claude 幫妳 —— 貼一句話，它幫妳把整套弄好（推薦先試這條）
  • 🖐 自己動手：在 GitHub 網站點一點 —— 不用終端機、不用寫程式，全程在瀏覽器裡

兩條路的結果一樣：一個 妳的帳號.github.io/… 的網址。

// 路 A ・ 叫 Claude 幫妳（最省事）

如果妳已經在用 Claude Code、也裝好了 Git，直接跟它說：

貼這句／講這段幫我把這個網頁用 GitHub Pages 放到網路上，給我一個永久的網址。過程如果需要我登入 GitHub、或做什麼決定，請一步一步告訴我怎麼做。

它會幫妳建好倉庫（repository）、上傳檔案、開啟 Pages；過程中會請妳登入一個免費的 GitHub 帳號，照它說的點就好。卡住就把畫面截圖丟群組。

// 路 B ・ 自己在 GitHub 網站做（不用終端機）

全程在瀏覽器點一點就好。跟著五步走 🌿

1

註冊一個 GitHub 帳號

到 github.com 按 Sign up，用 Email 註冊一個免費帳號。妳取的帳號名稱之後會出現在網址裡，建議簡單好記。

網址github.com
2

開一個新倉庫（Repository）

右上角 ＋ → New repository：

  • Repository name：取個英文名字，例如 my-page
  • 選 Public（公開，這樣網頁才看得到）
  • 勾 Add a README file
  • 按 Create repository

「倉庫」就是放這個網站所有檔案的資料夾。

3

上傳妳的網頁檔案

在倉庫頁面按 Add file → Upload files，把 AI 幫妳做好的網頁檔案拖進去，最後按 Commit changes。

⚠️ 最重要一件事：主頁檔名要叫 index.html
GitHub 會自動把 index.html 當成首頁。如果妳的檔案叫別的名字（例如 mypage.html），先把它改名成 index.html 再上傳。
4

開啟 GitHub Pages

倉庫上方 Settings（設定）→ 左邊 Pages：

  • Source：選 Deploy from a branch
  • Branch：選 main、資料夾選 /(root)
  • 按 Save
5

拿到妳的網址

存檔後，在同一頁 Pages 上方會出現妳的網址，長這樣：

妳的網址https://妳的帳號.github.io/my-page/

第一次可能要等幾分鐘（最多 10 分鐘）才生效 —— 出現網址後點點看，開得出來就成功了 ✨

看到自己的網頁掛在一個正式網址上 —— 那就是「我也有一個作品在網路上」的證明 🌷
🆘 卡住了？很正常，這樣做：
· 網址點開是空白／404 → ①等滿 10 分鐘再試 ②確認主檔叫 index.html ③確認倉庫是 Public
· 找不到 Settings 裡的 Pages → 往左邊選單下面找「Pages」
· 改了內容網頁沒變 → 一樣「Add file → Upload files」把新檔傳上去、Commit，等幾分鐘就更新
· 整個卡住 → 截圖丟群組，或直接叫 Claude 幫妳（路 A）💛
