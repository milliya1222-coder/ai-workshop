第 3 堂 ・ 9/23（三）

把心裡的東西
變成一頁網頁

而且今晚就真的上線 ——
妳會拿到一個可以傳給別人的網址 🌱

今晚是這四堂裡最有成就感的一晚。

結束的時候，妳手上會有一個真的網址 —— 可以貼進 IG 簡介、可以傳給客戶、可以傳給妳媽媽看。

🎒 今晚請先準備好這些
・妳想放上去的文字（服務介紹／活動說明／自我介紹，草稿就好）
・二到五張照片（自己的、作品的、空間的都可以）
・想好一件事：這一頁是要給誰看的？看完你希望她做什麼？

沒準備好也能來 —— 但準備好的人，今晚會走得比較遠 🌷

// 今天我們會做的

  • 把「我想做一頁網頁」講到 AI 真的聽懂
  • 做出來 → 看一眼 → 說哪裡不對 → 它改（來回這一段才是重點）
  • 把它推上網，拿到一個真的網址
  • 加碼：想再往前一步的，我們裝 Claude Code

帶走：自己的一頁網頁 ＋ 一個能傳出去的網址。

// 跟著貼、跟著做

1

先把「要給誰看」講清楚

這一步大部分人會跳過，然後做出一頁很漂亮但沒有用的網頁。

複製貼進 Claude我要做一頁網頁。先幫我想清楚再動手。 這一頁是給【誰】看的。 她現在的狀態是【她在煩什麼／在找什麼】。 我希望她看完之後【做什麼：私訊我／報名／認識我】。 我手上有這些內容： 【貼上妳的文字，草稿就好】 先不要做網頁。 請先告訴我：這一頁應該分成哪幾段？每一段要放什麼？ 還有——我漏掉了什麼她會想知道的？
💡 讓它先當企劃，再當設計師。這一步多花三分鐘，後面少改二十分鐘。
2

叫它做出來

接著貼好，照這個架構做成一頁網頁。 風格：【溫暖療癒／乾淨簡約／手作感／自然質樸……挑一個】 配色：【妳的顏色，例如「米白底＋暖棕＋一點玫瑰粉」】 字要好讀，留白多，手機看要舒服。 規則： ・不要用會閃、會跳的動畫 ・最下面放一個【聯絡我／報名】的按鈕 ・照片的位置先留白框，我等一下換成自己的 做好直接show給我看。

然後開始來回。不喜歡就直說，一次講一件事：

「標題太小了，放大一點」
「這個粉色太甜了，換成灰一點的」
「第二段跟第三段對調」
「加一段『常見問題』，放三個問題」
「手機上看太擠了，行距加寬」
💛 來回五六次是正常的，不是妳不會講。我自己做網頁也是這樣 —— 沒有人第一次就講得出自己要什麼，是看到了才知道自己不要什麼。
3

換上妳自己的照片

把照片直接拖進對話框，然後說：

接著貼把這幾張照片放進網頁裡。 第一張放最上面當主視覺，其他的放在【哪一段】。 照片不要變形，手機上也要好看。
⚠️ 照片裡有別人嗎？ 客戶、學員、孩子的臉，沒問過就不要放上公開網頁。這條線跟第一堂那條是同一條 🌿
4

推上網 —— 拿到妳的網址

這一段是今晚的重頭戲，只要三個動作：

  1. 在網頁那個視窗的右上角，找到下載的圖示 → 存下那個 .html 檔（記得存在找得到的地方，例如桌面）
  2. 打開 app.netlify.com/drop
  3. 把剛剛那個檔案直接拖進去

幾秒鐘後，網址就出來了 ✨

網址很醜怎麼辦？ 它會給妳像 wonderful-cat-123.netlify.app 這種名字。
註冊一個免費帳號（用 Google 登入就好），就可以改成 妳的名字.netlify.app，而且之後還能繼續更新它。
🌷 拿到網址的那一刻，先停下來。傳給一個人看 —— 妳的伴侶、妳的朋友、妳的孩子都好。那個「我做的」的感覺，值得被好好收下。

// 加碼：想再往前一步的

＋

裝 Claude Code（終端機版）

這一段是選配的。桌面 App 已經能讓妳做出網頁跟上線了 —— 這一步是給「想讓它直接動我電腦裡的檔案」的妳。

差別在哪：桌面 App 是妳把東西貼給它；Claude Code 是它直接在妳的資料夾裡工作 —— 建檔案、改檔案、整理一整個專案。

🍎 Mac

  1. Spotlight（⌘ + 空白鍵）搜「終端機」打開它
  2. 貼這一行，按 Enter：
    curl -fsSL https://claude.ai/install.sh | bash
  3. 跑完之後，關掉終端機再重開
  4. 打 claude 按 Enter，照指示登入

🪟 Windows

  1. 開始功能表搜「PowerShell」打開它
  2. 貼這一行，按 Enter：
    irm https://claude.ai/install.ps1 | iex
  3. 跑完之後，關掉 PowerShell 再重開
  4. 打 claude 按 Enter，照指示登入
⚠️ 那個黑黑的畫面不可怕。它只是另一種跟電腦說話的方式 —— 不用滑鼠，用打字。妳只要會複製貼上就夠了。跑出一堆英文是正常的，讓它跑完就好。

裝好之後，第一句話：

貼進終端機請在我的桌面建一個叫「我的工作區」的資料夾， 裡面放一個 hello.txt， 內容寫上今天的日期， 還有一段你作為我的工作夥伴想對我說的話。

它動手前會問妳可不可以 → 選 Yes。跑完去桌面看看 🌿　想停下來？按 Esc。

🆘 卡住了？

  • 找不到下載按鈕 → 在網頁預覽視窗的右上角，或跟它說「請給我這個網頁的檔案」
  • Netlify 拖進去沒反應 → 確認拖的是 .html 檔本身，不是資料夾
  • 網址打開是空白的 → 回去跟 Claude 說「網頁打開是空白的，幫我看看」，再重做一次檔案
  • 照片沒出現 → 照片要跟網頁檔一起上傳，或請它把照片直接嵌進網頁裡
  • 終端機裝一半卡住 → 沒關係，今晚不用裝完。桌面 App 就夠妳做完今天的作業了
